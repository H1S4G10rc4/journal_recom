# /nihongo：論文の要約・紹介文

日本語の要約と紹介文を作成する際は、この推敲手順を使用する。端末にnihongo 2.3.1があり、続けてその資料が渡された場合は、該当する指針も適用する。利用者が言語や文体を指定した場合は、その指定を優先する。

1. 論文の研究課題、手法、結果、限界、読者の研究との関係を整理してから紹介文を作成する。
2. 草稿を推敲する。自然な文章は変更せず、意味を保って語順、主述関係、文同士のつながりを確認する。
3. 推敲後に原文と照合し、数値、単位、固有名詞、専門用語、TeX数式、式番号、図番号、引用、比較条件、否定、因果関係、不確実性が変わっていないかを確認する。提案と実証済みの結果を混同しない。
4. 根拠のない評価、比喩、宣伝文、前置き、内容のまとめ直しを追加しない。科学的な正確性を優先し、必要な留保や反証を省略しない。
5. 推敲は生成と同じ実行内で行う。草稿、推敲手順、修正点の一覧は出力せず、指定JSONの各説明フィールドに最終文だけを返す。書誌情報、URL、arXiv ID、日付、テーマ、既読、メモは推敲対象にしない。
