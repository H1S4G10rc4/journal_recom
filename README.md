# Paper Desk

研究内容を自然な言葉で伝えると、2つのテーマから毎日1本ずつ論文を選び、日本語の紹介文と原図を表示する個人用デスクトップアプリです。既読とメモを保存し、次の推薦にも反映します。

ChatGPTアカウントで接続し、各利用者のPCで動作します。アプリ用のパスワードは初回に自分で設定します。

## ダウンロードと動作環境

[GitHub Releases](https://github.com/H1S4G10rc4/journal_recom/releases/latest) の「Assets」から、お使いのOSに合うファイルを選んでください。

| お使いのPC | 選ぶファイル |
| --- | --- |
| Linux x64 | `linux-x64.tar.gz` または AppImage |
| Windows x64 | `setup.exe`（インストール）または `portable.exe`（そのまま起動） |
| macOS Apple Silicon（Mシリーズ） | `mac-arm64.dmg` または `mac-arm64.zip` |

論文の調査にはインターネット接続と、Codexを利用できるChatGPTアカウントが必要です。アプリの実行に必要なソフトウェアやNoto Sansのフォントは同梱しています。

Windows・macOSの配布物には発行元証明書による署名がないため、OSから警告が表示されたり、起動を制限されたりする場合があります。

### Linux

`tar.gz` を展開し、フォルダー内の `paper-desk-desktop` を起動します。フォルダー内のファイルは移動せず、まとめて保管してください。AppImageの実行にはFUSE 2が必要です。FUSE 2を利用できない環境では `tar.gz` 版を使用してください。

### Windows・macOS

Windowsはファイル名の末尾が `setup.exe` のものを実行してインストールするか、`portable.exe` を直接起動します。macOSは `dmg` を開くか `zip` を展開し、Paper Deskを「アプリケーション」フォルダーへ移動します。

## 初回設定

1. アプリを起動し、「ChatGPTでログイン」から公式サイトで認証します。
2. アプリ用のパスワードを8文字以上で設定します。
3. 研究目的、2つのテーマ、使用する手法、読みたい範囲、先行研究、紹介文の好みについて、7つの質問に自然な言葉で答えます。
4. 推薦方針、更新時刻、タイムゾーンを確認して保存します。
5. 初回の推薦が完了すると、論文ライブラリに最大2本が表示されます。

ChatGPTの接続を後回しにし、先に研究の設定を保存することもできます。未接続の状態では論文を調査しません。先行研究を回答する際は「読了した論文」と「名前を知っている論文」を分けると、重複を避けやすくなります。

## 推薦と読書記録

- arXivで公開されている論文を対象とし、各テーマから1日最大1本を選びます。適切な候補が確認できない場合は本数を減らし、更新記録に理由を残します。
- 初回投稿から1か月以内の新着を優先しますが、研究との関連性と本文の確認を重視します。
- 背景、手法、結果、研究との関連、読むべき節や図を紹介します。数式はTeXで表示します。
- 原図は出典、確認できたライセンス、加工内容とともに表示します。取得できない図は省略し、記録に残します。
- 読了のチェックとメモは自動保存します。同じ日の再実行では保存済みのテーマの論文を置き換えません。
- 日本語の要約・紹介文には、同梱の **nihongo 2.3.1** と技術文書・推敲の参照資料を毎回適用します。数値、専門用語、数式、引用、因果関係、不確実性を維持するよう指示しています。

紹介文には誤りや確認漏れが含まれる可能性があります。研究で引用する前にリンク先の原文で内容を確認してください。

## 毎朝の更新

初期の更新時刻は06:00です。タイムゾーンは初回設定を行ったPCの設定を使用し、画面から変更できます。

デスクトップアプリは研究の設定を保存するとPC起動時の自動起動を設定します。ウィンドウを閉じてもトレイに常駐し、パスワードでロック解除した後はバックグラウンドで更新します。「終了」を選ぶと停止します。再起動後は一度ロックを解除してください。

PCが休止中の場合は更新できません。復帰後にその日の未生成分を補います。自動更新が失敗した場合は15分間隔で最大3回試し、その後は4時間待ちます。画面の「今日の推薦を更新」から手動で再試行できます。

## 保存する情報と外部への送信

研究内容、推薦履歴、既読、メモ、取得した図は利用者のPCに保存します。研究内容と読書記録、図は、アプリ用のパスワードから導出した鍵で暗号化します。パスワードを紛失すると、保存済みデータを復元できません。

推薦を生成する際は、回答した研究内容、過去の推薦、既読、メモをOpenAIへ送信します。論文と原図はarXivなどから取得します。アプリ提供者がこれらを収集するサーバーや、クラウド同期の機能はありません。

ChatGPTのログイン情報は、同梱した公式Codex CLIがアプリ専用の保存先で管理します。OSの認証情報ストアが利用できる場合はそちらを使用し、利用できない場合は専用領域の認証ファイルを使用します。**アプリ用パスワードは、この認証ファイルを暗号化するものではありません。**

画面の「データを書き出す」で、研究設定と読書記録をJSONに保存できます。書き出したファイルは暗号化されないため、共有先に注意してください。

## 問題が起きたとき

「選定・更新の記録」を開くと、選定理由、本文の確認範囲、失敗した処理を確認できます。ChatGPTの利用上限に達した場合は時間をおいて再実行してください。認証エラーの場合は設定画面からChatGPTに接続し直してください。

不具合は [GitHubの不具合報告ページ](https://github.com/H1S4G10rc4/journal_recom/issues) で報告できます。使用OS、アプリのバージョン、再現手順、エラー文を記載し、パスワード、認証ファイル、非公開の研究内容は添付しないでください。
