# Paper Desk

研究内容を自然な言葉で伝えると、毎朝、研究に読む価値のある論文を2本選んで紹介する個人用デスクトップアプリ。既読やメモも次の推薦の手がかりにします。

## はじめ方

1. 自分のOS向けのアプリをダウンロードして起動します。
2. 「ChatGPTでログイン」から公式サイトで認証します。対応するChatGPTプランの利用枠を使用します。
3. アプリ用のパスワードを初回に設定します。
4. 研究目的、2つのテーマ、手法・課題、選定範囲、先行研究、説明の好みについて、7つの質問に普段の言葉で答えます。
5. 推薦方針と更新時刻を確認して保存します。その日の2本の調査を開始します。

ChatGPTの接続を後回しにして、先に研究の設定を保存することもできます。未接続の状態では論文を調査しません。名前を知っている研究と読了した論文は、回答で区別してください。

## 毎朝の動作

- 毎日最大2本、各テーマから1本。arXiv公開論文を対象とします。
- 初回投稿が過去1か月以内の新着を優先し、関連性と確認できた内容を重視します。
- 本文の背景・手法・結果・研究への関連・読みどころを紹介します。数式と、出典付きの原図も表示します。
- 既読とメモは自動保存します。重複紹介はarXiv IDと日付・テーマで防ぎます。
- パスワードでロック解除した後は、ウィンドウを閉じてもトレイに常駐して更新します。「終了」を選ぶと止まります。
- PCの起動時にアプリが開きます。再起動後は一度パスワードを入力してください。PC休止中には動作せず、復帰後にその日の分を補います。
- ネットワーク切断や利用上限のエラーは画面に表示します。自動更新の失敗は15分間隔で最大3回試し、その後4時間待ちます。手動で再試行できます。

## 保存先とプライバシー

各利用者のPCのアプリデータ領域に保存します。研究内容・推薦履歴・メモはscryptとAES-256-GCMで暗号化します。原図も暗号化して保存します。アプリ用パスワードを紛失するとデータを復元できません。必要に応じて画面からデータを書き出してください。書き出すJSONは暗号化されていません。

推薦のために研究内容、関連する読書記録、メモをOpenAIに送信し、公開論文をarXivなどから取得します。アプリ提供者に送信するサーバー、アクセス解析、共同データベースはありません。ChatGPTの接続情報は専用のCodex保存領域で公式CLIが管理します。OSの認証情報ストアが利用可能ならそちらを使い、利用できなければローカルの認証ファイルに保存されます。アプリ用パスワードはChatGPTの認証情報ファイルを暗号化するものではありません。

独自の初期パスワード、開発者のChatGPTアカウント、研究内容、推薦履歴は配布物に含みません。既存のCodex設定やログインにも干渉しません。アプリは127.0.0.1だけで待ち受け、起動時の能力トークンとセッションでローカル画面を保護します。

## 開発・配布

Node.js 24を使います。利用者はNode.jsやPythonを別途インストールする必要はありません。

```bash
npm ci
npm test
npm start
# 自分のOS向けの配布ファイルを生成
npm run dist -- --publish never
```

開発用ブラウザ画面は `npm run prepare:resources && npm run preview` で起動します。表示されるURLを直接開いて使用できます。初回にパスワードを設定し、以後はパスワードでロックを解除します。ポートは `PORT`、保存先は `PAPER_DESK_STATE` で指定できます。

- Linux: tar.gzを展開し、`paper-desk-desktop` を起動します（追加のNode.js/Pythonは不要）。FUSE 2がある環境ではAppImageも利用できます。
- Windows: セットアップexe / ポータブルexe
- macOS: dmg / zip

`v0.1.0`などのタグをGitHubへpushすると、同梱のGitHub Actionsが各OS上でビルドし、ダウンロード可能なActions artifactを生成します。公開リリースへのアップロードは自動では行いません。各OSで初回ログイン、設定、翌日の更新まで動作を確認してからReleaseに載せてください。macOSのDeveloper ID署名・公証、Windowsのコード署名は公開者の証明書が必要です。このソースには署名資格情報を含みません。

現在の公開準備版は、利用者のPCで動くオープンソースとしてCodex app-serverの認証を使用します。商用・ホスト型サービスへ変更する場合は、そのままこの認証方式を流用せず、公式のSign in with ChatGPTへ移行してください。

## 日本語の要約生成

要約・紹介文の生成と推敲には同梱のnihongo 2.3.1を使用する。スキル本体と技術文書・レビュー・書き言葉の参照資料を各生成リクエストに含めるため、利用環境にnihongoを別途インストールする必要はない。推敲後は原文と照合し、数値、専門用語、TeX数式、引用、因果関係、不確実性を維持するよう指示する。既存の紹介文、既読、メモは書き換えない。
